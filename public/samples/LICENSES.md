# Editor instrument samples — sources and licenses

All files in this folder were converted from the sources below with `packaging/build_editor_samples.py`
(trimmed, faded, one gain per instrument, 44.1 kHz MP3). Only sources whose license permits
redistribution are used. Original archives are not part of the repository.
