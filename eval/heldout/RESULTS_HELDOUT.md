# 홀드아웃 실제 믹스 벤치마크 결과 (2026-10-24)

`eval/RESULTS.md`의 비교는 현행 파이프라인의 학습·튜닝에 쓰인 개발셋(베이스 6곡, 드럼 8곡) 위에서 이뤄져
현행에 유리했다. 이 문서는 **비교하는 어느 시스템도 학습에 쓰지 않은** 공개 데이터셋에서
**같은 분리 → 전사 조건**으로 다시 잰 결과다. 이 결과로 드럼 기본값을 `adtof`로 바꿨다(연구용).

## 테스트셋

| 세트 | 내용 | 정답 | 오염 점검 |
|---|---|---|---|
| Slakh2100 **test** 20곡 | 렌더링 믹스, 트랙 ID 순 조건 충족 앞 20곡, 30~90초 구간 | 베이스·드럼 MIDI | 현행 파이프라인은 Slakh 미사용. YourMT3+는 Slakh **train**만 사용(같은 렌더러라 유리한 조건). ADTOF `adtof-all`은 Slakh 미사용 |
| MDB Drums 23곡 | MedleyDB 실제 녹음 믹스, 전곡 | 드럼 subclass 주석 | 세 시스템 모두 미사용(YourMT3+ 논문 학습 목록에 없음, ADTOF `adtof-all` = adtof_yt + adtof_F70) |

- 데이터 생성: `eval/heldout/fetch_heldout.py` (Slakh는 HF 미러 `DreamyWanderer/Slakh2100-FLAC-Redux-Reduced`, MDB는 GitHub `CarlSouthall/MDBDrums`). 데이터와 런 산출물은 gitignore.
- 분리: htdemucs, `DEMUCS_DEVICE=mps`. 곡별 결과를 캐시한다.

## 채점

- 베이스 대표값은 **옥타브 무관(pitch class) onset F1**(50 ms)이다. Slakh 베이스 패치는 정답 pitch < 35(B1)를 한 옥타브 위로 렌더링한다(Track01876 실측: Basic Pitch·YourMT3+ 모두 35 미만만 정확히 +12, 35 이상은 일치). 그래서 Slakh 정답의 옥타브는 오디오와 어긋날 수 있다. 엄격 F1(`f1_strict`)과 offset F1(offset_ratio 0.2)도 함께 낸다.
- 드럼은 세 시스템이 모두 표현하는 **공통 5클래스**(kick, snare, hihat=closed+open, tom, cymbal=crash+ride) micro F1이다. 매핑에 없는 퍼커션은 정답·출력 양쪽에서 제외한다.
- 양쪽 모두 첫 0.1초 온셋은 제외한다(구간 자르기로 생긴 잘린 노트 때문).
- 평균은 곡별 평균이다. CI는 곡 단위 부트스트랩(10,000회, seed 0) 95%다. "기준 대비 차이"는 같은 곡끼리의 paired 차이다.

## 해석

1. **드럼:** 실제 녹음(MDB)에서 ADTOF가 이전 기본값보다 +0.31(CI +0.25~+0.38)이다. 심벌은 0.00 → 0.68이다. 렌더링(Slakh)에서는 차이가 유의하지 않다. → **드럼 기본값을 `adtof`(스템 입력)로 교체**했다.
2. **YourMT3+ 드럼**은 렌더링 0.806 / 실제 녹음 0.636으로 차이가 크다. 같은 공개 데이터(Slakh 포함)로 대량 학습한 모델도 실제 녹음으로는 잘 전이되지 않는다.
3. **베이스:** YourMT3+(믹스 입력) 0.850 vs 현행 0.574(+0.28, CI +0.20~+0.36)이다. 단 렌더링 조건이고, YourMT3+는 Slakh train으로 학습했다. **실제 녹음 베이스 테스트셋이 생길 때까지 베이스 기본값은 유지**한다.
4. 현행 베이스 후처리를 YourMT3+ 출력에 붙이면 이득이 대부분 사라진다(0.722 → 0.599). 후처리가 개발셋에 맞춰져 있다.

## 한계

- 실제 녹음 베이스 테스트가 없다.
- Slakh 20곡은 30~90초 구간만 썼다.
- MDB는 MusicDelta 계열 짧은 곡 위주다.
- ADTOF는 5클래스만 출력하므로 9클래스 체계(오픈/클로즈 하이햇, crash/ride)의 비교는 하지 않았다.
- 같은 곡을 API 경로로 다시 돌린 결과(MDB Punk)가 0.896 vs 벤치마크 0.904로 근소하게 달랐다. 분리 실행 간 차이로 추정하며 미확인이다.
